About BOB’sLAB

BOB’sLAB is a creative VR physics sandbox designed and developed by 26Th Studio. Players can experiment, build, interact with objects, and explore a world driven by advanced physics simulation.

Privacy Policy

Last Updated: 30/01/2026

1. Data We Collect

BOB’sLAB collects a User ID provided by the Meta Horizon platform. This identifier is used to support basic application functionality and is not directly identifiable information such as a real name or email address.

2. How We Use This Data

The User ID is used solely for core app functionality, including saving and restoring player progress and maintaining a consistent application state across sessions.

The User ID is not used for advertising, analytics, tracking, personalization, social features, multiplayer features, or monetization.

3. Data Sharing

No user data is shared with third parties, service providers, advertisers, or analytics platforms.

4. Data Retention

User ID data is retained only as long as necessary to support the application’s functionality.
